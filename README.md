# 쥐구멍에도 볕 들 날

쥐구멍 속 집에 사는 쥐 가장이 식구를 먹여 살리려고 매일 밤 벽 밖으로 나서는 이야기. 바늘 검과 병뚜껑 방패를 들고 쥐덫, 인간의 발, 고양이 보스를 넘어 먹이를 구해 돌아오는 3D 액션 어드벤처 웹 게임입니다.

three.js(r128) 하나만 쓰는 단일 HTML 파일이라 빌드 없이 브라우저에서 바로 열립니다.

## 제1장 · 첫 번째 밤

- 먹이 다섯 개를 모은다. 빵 부스러기 셋과 덫 위의 치즈 넷이 있다.
- 덫은 칼로 먼저 쳐서 터뜨리면 치즈를 안전하게 주울 수 있다.
- 인간의 발은 바닥에 붉은 그림자를 띄운 뒤 내려찍는다. 방패로 막을 수 없다.
- 고양이는 덮치기와 물기를 쓴다. 방패로 막을 수 있고, 덮친 직후가 빈틈이다. 졸 때 치면 기습 피해가 두 배다.
- 고양이를 쫓아낸 뒤 쥐구멍으로 돌아가면 끝난다.

## 조작

| | PC | 모바일 |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 화면 끌기 |
| 시점 | 마우스 끌기 | 오른쪽 화면 끌기 |
| 칼 | Space / J | 칼 버튼 |
| 방패 | Shift / K (누르고 있기) | 방패 버튼 (누르고 있기) |
| 구르기 | E / L | 구르기 버튼 |

## 실행

```sh
npx serve .        # 또는 python3 -m http.server
```

`index.html`을 브라우저로 열어도 됩니다.

## 구조

```
index.html                     게임 (빌드 결과물)
src/                           게임 소스 조각
  head.html                    HTML, CSS, HUD, 렌더러 설정
  lib.js                       SDF 조형(surface nets), 털 셸 셰이더, 환경 텍스처
  game.js                      캐릭터, 월드, 게임 규칙과 AI
  post.js                      블룸·색보정·비네트·그레인 후처리
  quality.js                   화질 단계(털 겹·그림자·해상도·블룸)와 자동 조절
  tail.js                      입력, 루프, 로딩
build.sh                       src/ → index.html
docs/plan-upgrade.md           고도화 기획안
samples/graphic-styles.html    그래픽 스타일 샘플 5종 (클레이, 셀, 느와르, 다크 판타지, 페이퍼크래프트)
samples/character-sculpts.html 다크 판타지 기준 캐릭터 조형 3안 (리얼 퍼, 영화풍 스컬프트, 그림다크)
```

캐릭터는 외부 모델 없이 코드로 빚습니다. 타원체와 캡슐을 부드럽게 합친 SDF를 surface nets로 메시화하고, 털은 메시를 여러 겹 바깥으로 밀어 그리는 셸 기법으로 표현합니다.

- 메시화는 Web Worker 여러 개에서 병렬로 돌고, 결과는 IndexedDB에 캐시됩니다. 조형 모양이 바뀌지 않았으면 두 번째 실행부터 메시화를 건너뜁니다.
- 화질은 낮음·보통·높음 세 단계(털 겹 6·10·14, 그림자 맵 512·1024·2048, 해상도 배율 상한 1·1.25·2, 블룸 샘플 8·12·20)입니다. 기본값 '자동'은 PC는 높음, 모바일은 보통에서 시작해 프레임이 42fps 밑으로 떨어지면 한 단계씩 낮춥니다. 시작·엔딩 카드의 화질 버튼으로 직접 고를 수 있고 선택은 브라우저에 저장됩니다.

## 배포

Vercel에서 이 레포를 Import 하면 됩니다. 정적 사이트라 빌드 명령과 출력 폴더 설정이 필요 없습니다(`index.html`을 루트에서 바로 서비스).
