## 0. 한 줄 방향

제1장을 "보기 좋은 데모"에서 **소리·연기·연출이 있는 한 편의 단편**으로 끌어올리고, 그 위에 **아버지의 인생 다섯 밤**이라는 장 구조를 세웁니다.
마지막 밤 새벽, 쥐구멍 안으로 처음 햇살이 들어오는 장면이 제목 "쥐구멍에도 볕 들 날"의 답입니다.

## 1. 이야기 축: 다섯 밤 (장 구성안)

밤이 지날수록 부엌은 더 위험해지고, 아버지는 늙어 갑니다. 아이들은 자랍니다.

| 장 | 제목(가제) | 계절 | 아버지 | 목표 | 새 위협 | 감정 축 |
|---|---|---|---|---|---|---|
| 1 | 첫 번째 밤 | 가을 | 젊음, 체력 5 | 먹이 5 | 덫, 인간 발, 고양이 (현재 구현) | 책임의 시작 |
| 2 | 비 오는 밤 | 장마 | 체력 5 | 먹이 6 | 물웅덩이(미끄러짐), 끈끈이 덫, 쫓기 고양이 | 지붕 새는 집, 아이들 추위 |
| 3 | 약을 구하러 | 초겨울 | 체력 4, 흰 털 몇 가닥 | **막내의 약** 1개 (찬장 위) | 높이 차(의자·서랍 오르기), 통발 | 처음으로 두려움 |
| 4 | 겨울밤 | 한겨울 | 체력 4, 구르기 쿨 ↑ | 먹이 5 + 귀가 시간 제한(촛불) | 쥐약 미끼(먹으면 안 됨), 고양이 2차전(상처 입은 고양이) | 노쇠, 버팀 |
| 5 | 볕 드는 날 | 봄 새벽 | 체력 3, 지팡이 같은 바늘 | 아들과 함께 귀가 | 고양이 최종전 (아들이 보조) | 세대 교체, 새벽 햇살 엔딩 |

- 장 사이: 쥐구멍 안 집 장면(짧은 컷신) — 식탁에 먹이를 내려놓는 장면, 아이들 키가 장마다 자라 있음.
- 노쇠는 **수치로 체감**되게(체력 상한, 구르기 쿨, 걷는 자세 굽음, 털색 회색 섞임). ☑ **수치로 체감** (확정) ☐ 연출로만
- 대사는 음성 없이 자막. 쥐들은 말하지 않고 몸짓으로, 자막은 아버지 내레이션 한두 줄만.

**이번 고도화에서 만들 장 범위 — 확정**
- ☑ **A. 제1장 완성도 + 제2장까지 (확정)** (추천: 품질 기준을 먼저 1장에서 세우고, 2장에서 확장성 검증)
- ☐ B. 다섯 장 전부 짧게 (흐름 우선, 장당 품질은 낮음)
- ☐ C. 제1장만 영화 수준으로

## 2. 단계별 계획

각 단계 끝에 플레이 가능한 빌드 + 커밋. 순서는 "모든 장에 공통으로 쓰이는 기반"부터.

### 1단계 · 기반: 로딩, 성능, 배포 (약 1회 작업)

> **진행 (2026-11-22)**: 캐시·워커·화질 단계 완료. 헤드리스 크롬(데스크톱 CPU) 기준 로딩: 이전 조형만 1.8초 → 첫 실행 전체 1.5초(조형 0.87초) → 캐시 실행 0.7초(조형 0.21초).
> 화질 단계는 털 겹 6·10·14로 확정(16은 현재 14와 차이가 작아 보류). 남은 것: Vercel Import(사용자), 실제 폰 fps 측정.
- **조형 캐시**: SDF → 메시 결과(위치·법선·색·털 버퍼)를 IndexedDB에 저장, 소스 해시가 같으면 재사용. 두 번째 실행부터 로딩 수 초 → 거의 즉시.
- **조형을 Web Worker로**: 단일 HTML 유지 위해 Blob URL 워커. 첫 실행에도 메인 스레드가 멈추지 않아 로딩 화면에 진행 막대·연출을 띄울 수 있음.
- **품질 단계 자동 조절**: 저/중/고 프리셋(털 겹 6·10·16, 그림자 맵 512·1024·2048, DPR, 블룸 해상도). 처음 3초 프레임 시간을 재서 자동 선택, 설정 메뉴에서 수동 변경.
- **Vercel 연결**: 레포 Import(정적, 빌드 명령 없음) → README에 플레이 링크. Vercel 계정 연결은 사용자가 한 번 해 주셔야 함(아래 7절).
- 실제 폰(가능하면 중급 안드로이드 + 아이폰)에서 fps 측정 → 수치를 이 문서에 기록.

### 2단계 · 캐릭터 연기: 뼈대 애니메이션

> **진행 (2026-11-22)**: 자동 스키닝, 쥐 애니메이션(대기·걷기·달리기·3연타·방패·막기 반동·구르기·피격·무릎 꿇는 쓰러짐·줍기·귀가·노쇠 매개변수), 고양이(졸기·웅크려 걷기·덮치기 웅크림과 엉덩이 흔들기·도약 자세·물기·피격·꼬리 감정과 털 부풂), 발 고정 보행과 다리 IK 완료.
> 고양이가 사냥 중 거리 5.2까지 다가오도록 바뀜(이전엔 제자리). 칼 3연타는 판정·타이밍이 같고 모양만 다름.
> 보류: 네 발 전력질주(양손에 칼·방패를 든 채라 어색해서 보류, 원하시면 칼을 입에 무는 연출로 추가 가능), 앞발 휘두르기 애니메이션은 5단계 공격 패턴과 함께. 먹이 줍기는 몸을 숙이는 동작만(등짐 표시는 망토와 겹쳐 보류).
현재 쥐는 몸통이 통째로 기울고, 고양이는 걷지 못합니다. 이게 "영화 수준"과 가장 거리가 먼 부분입니다.

**방식 — 확정**
- ☑ **자동 스키닝 (확정)**: 지금 SDF 프리미티브마다 뼈를 지정하고, smooth-min에서 각 프리미티브가 기여한 정도로 정점 가중치를 자동 계산 → `SkinnedMesh`. 셸 털은 스키닝 전에 법선 방향으로 밀어 함께 휘어짐. 이음매가 없고 몸통이 실제로 굽음.
- ☐ 부위 분리: 몸통을 골반·가슴·목으로 쪼개 그룹 계층으로 움직임. 구현은 쉽지만 관절 이음매가 보이기 쉬움.

**애니메이션 목록** (코드로 쓰는 절차적 애니메이션 + 상태별 블렌딩)
- 쥐: 대기(숨쉬기·수염 떨림·주변 살피기), 걷기, 달리기(네 발로 내려가는 전력질주 ☐ 넣을까?), 칼 3연타, 방패 자세, 구르기, 피격 움찔, 넘어짐/사망, 먹이 줍기(입에 물거나 등에 메기), 승리 포즈, 노쇠 자세(장 진행에 따라 굽음).
- 고양이: 걷기·종종걸음(4족 보행 IK), 웅크리기(엉덩이 흔들기 = 덮치기 예고), 앞발 휘두르기, 물기, 졸기(배 오르내림·귀 까딱), 놀람, 꼬리 감정(평온 S자 / 사냥 끝만 까딱 / 분노 부풂·털 세움).
- 발이 바닥에 붙는 **발 IK**(미끄러지는 발 제거), 머리가 목표를 바라보는 **시선 추적**.

### 3단계 · 사운드
**방식 — 확정**
- ☑ **혼합 (확정)**: 효과음은 Web Audio로 코드 합성(단일 HTML, 저작권 걱정 없음). BGM은 감정 비중이 커서 **음원 파일**(CC0 또는 직접 제작한 피아노·현악) 사용 → `audio/` 폴더 추가, 단일 HTML 원칙만 예외.
- ☐ 전부 코드 합성: 단일 HTML 유지. BGM은 피아노·패드 절차 작곡이라 감동 연출에는 한계.
- ☐ 전부 음원 파일: 품질 최상, 음원 확보가 관건.

**목록**: 발소리(나무 바닥, 젖은 바닥), 칼 휘두름·명중, 방패 막기(병뚜껑 금속음), 구르기, 덫 튕김, 인간 발 경고 저음 → 쿵(화면 흔들림과 동기), 고양이 그르렁·하악·울음·방울 소리(방울은 **위치 단서** — 졸 때 조용, 움직이면 딸랑), 먹이 획득, 집 안 아이들 찍찍, 시계 초침(앰비언스), 비(2장).
- 3D 위치 음향(PannerNode)으로 화면 밖 고양이 방울 방향을 들을 수 있게.

> **진행 (2026-11-22)**:
> - **효과음**: 목록의 1장 분량을 모두 Web Audio 합성으로 만들었고, 3D 위치 음향을 넣었습니다. 젖은 바닥과 비는 2장 몫으로 남겼습니다.
> - **배경음악**: 저작권 걱정이 없도록 직접 작곡했습니다. `tools/compose_bgm.py`가 악보와 합성 악기로 `audio/` 아래 네 곡을 렌더링합니다(night·cat·home·fall, MP3 약 1.9MB).
> - **볼륨과 절약**: 소리 켬/끔은 카드 버튼이나 M 키로 바꾸고 설정은 저장됩니다. 탭이 가려지면 오디오를 멈춥니다.
> - **헤드리스 검증**:
>   - 이벤트 20종이 모두 울렸습니다.
>   - 곡 전환이 night → cat → night → home, 사망 시 fall 순서로 정상입니다.
>   - 반복 지점의 샘플 간 차이는 0.0002로, 평소 샘플 간 변화 0.0175보다 훨씬 작아 끊김이 없습니다.
>   - 실제 귀로 들어 보는 확인은 아직 못 했습니다. 음량 균형과 곡 분위기는 사용자 피드백을 받아 조정합니다.

### 4단계 · 연출과 이야기
- **인트로 컷신** (40초 내외, 건너뛰기 가능): 쥐구멍 안 집 — 잠든 아이들, 빈 그릇, 아내가 망토를 여며 줌 → 벽 틈으로 나서는 등 뒤 → 부엌의 달빛.
- **귀가 컷신**: 먹이를 식탁에 내려놓음, 아이들이 달려듦, 아버지가 상처를 숨기고 웃음.
- **쥐구멍 안 집을 실제 3D 공간으로**: 지금은 벽 텍스처 그림. 성냥갑 침대, 골무 그릇, 촛불 한 토막.
- **가족 리얼 퍼 재조형**: 아내(앞치마 천 조각), 아이 셋(크기·털색 다름, 막내는 3장의 약 이야기 주인공).
- 레터박스, 자막, 카메라 레일(코드로 키프레임), 장 제목 카드.
- 연출 품질 요소: 피사계 심도(컷신 한정), 촛불 깜박임 그림자, 숨결 김(겨울).

> **진행 (2026-11-22)**:
> - **집 내부**: 벽 속 집을 3D로 만들었습니다(실패 식탁, 골무 그릇, 병뚜껑 의자, 성냥갑 침대, 우표 그림, 바늘). 촛불이 깜박이며 그림자를 드리웁니다(화질 높음에서만).
> - **가족**: 아내와 아이 셋을 실제 털로 다시 조형했습니다. 아버지와 같은 형태를 털색·크기·머리 비율만 바꿔 쓰고, 같은 형태의 조형 작업은 한 번만 메시화하도록 바꿔서 로딩이 거의 늘지 않았습니다(캐시 실행 0.9초).
> - **컷신**: 인트로 6샷과 귀가 5샷, 각각 약 37초를 넣었습니다. 레터박스, 자막, 장 제목 카드, 건너뛰기(Esc), 컷신 마지막 구도에서 게임 카메라로 1.4초 동안 이어지는 전환이 들어 있습니다. 시작·엔딩 화면 뒤로는 집 안이 천천히 돌며 보입니다.
> - **막내의 기침**: 인트로와 귀가 모두에 넣었습니다(3장 복선).
> - **미룬 것**:
>   - 피사계 심도: 후처리 셰이더를 손봐야 해서 다음으로 미뤘습니다.
>   - 숨결 김: 겨울 장에서 넣습니다.
> - **성능 메모**: 집 안 장면은 가족 털 때문에 삼각형이 부엌보다 많습니다(높음 화질 기준 집 약 540만 개, 부엌 약 220만 개. 집은 보통 화질에서 약 360만 개).
>   - 이미 한 조치: 아이들은 털 겹을 60%만 그리고 프레임 밖이면 생략합니다. 촛불 그림자는 높음 화질에서만 켭니다.
>   - 폰에서 끊기면 다음 조치로 아이용 저해상도 조형(LOD)을 넣습니다.

### 5단계 · 전투·레벨 확장
- 고양이 패턴 추가: 앞발 휘두르기(방패로 막으면 크게 밀림), **쫓기 페이즈**(체력 절반 이하 → 달아나며 숨을 곳으로), 꼬리 휘두르기(구르기로만 회피).
- 숨는 곳: 그릇·행주·신발 밑 — 들어가면 고양이 시야에서 사라지고 발도 멈춤. 오래 숨으면 고양이가 냄새로 찾아옴.
- 높이 차: 의자 가로대·서랍 손잡이 오르기(3장 핵심).
- 덫: 끈끈이(속도 감소, 연타로 탈출), 통발(갇히면 칼로 문 비틀기), 쥐약 미끼(4장, 먹으면 체력 상한 감소 — 판단 요소).
- 체력 회복: 물방울(1칸), 집 안 휴식(장 사이 완전 회복).
- 조작감: 타격 정지(히트스톱 50ms), 피격 시 카메라 흔들림, 락온(☐ 넣을까? 고양이전에 Tab/모바일 버튼).

## 3. 이번 범위 추천안 (1절에서 A를 고를 경우)

| 순서 | 내용 | 결과물 |
|---|---|---|
| 1 | 1단계 기반 전부 | 빠른 로딩, 품질 자동, Vercel 링크 |
| 2 | 2단계 자동 스키닝 + 쥐 애니메이션 전부 + 고양이 걷기·웅크림·꼬리 | 제1장이 "연기하는" 캐릭터로 |
| 3 | 3단계 사운드 전부 (1장 분량) | 소리 있는 제1장 |
| 4 | 4단계 인트로·귀가 컷신, 집 내부, 가족 재조형 | 제1장 = 완결된 단편 |

## 4. 기술 구조 변경

- `src/` 조각 추가 (build.sh 연결 순서 유지, 최상위 이름 충돌 주의):
  - `worker.js` 조형 워커·캐시 · `rig.js` 자동 스키닝·IK·애니메이션 블렌딩 · `audio.js` 효과음 합성·BGM·3D 음향 · `story.js` 장 데이터·컷신 레일·자막 · `levels/ch1.js`, `ch2.js` 장별 맵·스폰·규칙 수치.
- 게임 규칙 수치를 장 데이터로 분리 (지금 game.js에 상수로 박혀 있음).
- 저장: 진행한 장과 설정을 localStorage에(없어도 처음부터 동작).
- three.js는 r128 유지(바꾸면 onBeforeCompile 털 셰이더 재검토 필요). ☐ 최신 버전으로 올리기는 이번엔 보류 추천.

## 5. 검증

- 규칙: 헤드리스 Chrome(swiftshader) + 고정 시간 `step(1/60)` 반복으로 장별 규칙 테스트. 테스트용 노출 코드는 커밋 전 제거.
- 화면: 각 단계마다 스크린샷(캐릭터 포즈 시트, 컷신 프레임)을 남겨 공유.
- 성능: 실제 폰 측정 — 이건 사용자 기기에서 Vercel 링크로 확인 부탁드립니다.
- 조작감·난이도: 1단계 배포 후 직접 플레이 피드백을 받아 2~5단계에 반영.

## 6. 하지 않는 것 (이번 범위 밖)

- 음성 연기, 다국어, 게임패드, 세이브 슬롯 여러 개, 다섯 장 전부의 완성(A안 기준).

## 7. 사용자에게 필요한 것

- Vercel: vercel.com에서 GitHub 레포 Import 한 번(또는 터미널에서 `vercel login` 해 두시면 제가 CLI로 연결).
- BGM을 음원 파일로 갈 경우: 원하는 분위기 참고곡 1~2개(직접 넣으실 곡이 있으면 그것도).
- 1단계 배포 후 폰에서 한 번 플레이 → 체감(끊김·난이도·조작) 메모.
